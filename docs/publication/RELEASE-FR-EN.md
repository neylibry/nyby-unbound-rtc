## English

Manual clock for **Pokémon Unbound on real GBA + SuperCard running
SuperFW 0.21, without an RTC chip**. Enter the current date/time at each boot;
it advances during play. The last entered setting is retained. Powered-off
time is not counted.

Download **NyBy-Unbound-RTC-v1.1RC1-FR-EN-Community-r4-2026-10-17.zip** from the attached assets, extract it on your PC, then
open **INSTALLER-FR-EN.html**. It works offline without installation, Python
or an account. English/French guides, screenshots and sources are included.

Prepare your own FireRed USA v1.0 → Unbound 2.1.1.1 → optional Antony French
2.1.179 translation → matching NyBy RTC patch. This installer handles only
the final RTC step, selected by the prepared Unbound file's fingerprint.
No ROM, complete translation, firmware or player save is included.

SuperFW: **PatchEngine, DirectSaving ON; SuperFW RTC, IGM and cheats OFF**.
Matching caches are supplied and must not be regenerated. Back up your save;
a matching-language native 128 KiB .sav can be copied without conversion.

**Status:** FR tried on GBA, smooth gameplay reported by NyBy. EN PC validated,
real-hardware testing pending. Intermittent disappearing Options choices
remain an open report. Native time restrictions apply; not every daily event
reset is guaranteed.

**r4 adds MIT licensing and publication material. The four patches, SuperFW
profiles and installer are byte-identical to r3. Existing r3 users do not need
to update their game or save.** Original NyBy code is MIT-licensed;
third-party rights in the game, translation and firmware remain separate.
Official downloads are free.

Substantial parts of the code and documentation were generated with Codex (AI), directed by NyBy. NyBy defined the requirements and performed the reported GBA testing. Hardware feedback concerns the French build; English hardware testing is still pending.
