TITLE: [Release candidate] NyBy RTC for Unbound EN/FR on SuperCard + SuperFW 0.21

[b]NyBy Manual RTC v1.1RC1 — real GBA, SuperCard, no RTC chip[/b]

This add-on provides an advancing software clock to Unbound on a real GBA
using a SuperCard without an RTC chip. Enter the real date and time in a
240x160 menu at every boot, then play normally. It remembers the last value
entered, rather than the time at shutdown. It cannot measure powered-off time.
Native day/night and calendar rules still apply; not every daily event is
guaranteed to reset after a manual date change.

[b]Supported builds[/b]
English Unbound 2.1.1.1 and Antony French 2.1.179, with SuperFW 0.21.
Both start with your own English FireRed USA v1.0:
EN: FireRed USA -> official Unbound 2.1.1.1 patch -> NyBy RTC EN.
FR: FireRed USA -> Unbound 2.1.1.1 -> Antony FR 2.1.179 -> NyBy RTC FR.
The NyBy installer performs only the final RTC step. Its fingerprint check
selects the matching RTC patch for your prepared build; it does not translate.

[b]Download and setup[/b]
[url=https://github.com/neylibry/nyby-unbound-rtc/releases/tag/v1.1-rc1-community-r4]Community ZIP, bilingual guides, BPS patches and source[/url]
Extract the community ZIP on a PC and open INSTALLER-FR-EN.html in a modern
browser. It works offline. Select prepared Unbound and optionally its matching
native 128 KiB .sav. Generate and extract your personal SD ZIP, keeping backups
of existing ROM/save files before copying. No ROM or personal save is supplied.

SuperFW: PatchEngine, DirectSaving ON; firmware RTC, IGM and cheats OFF.
The matching caches are included: do not run Generate patches.

[b]Validation and limits[/b]
French gameplay/save/resume have been tried on real GBA; NyBy reports smooth
gameplay with this optimized version. English calendar and native save/resume
checks passed on PC; English hardware testing is still needed. Intermittent
missing choices in the in-game Options menu remain an open report, so this is
RC1. No compatibility claim is made for other flashcarts or game versions.
