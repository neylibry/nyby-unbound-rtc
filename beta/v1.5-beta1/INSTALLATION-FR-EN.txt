INSTALLATION — NyBy RTC v1.5-beta1 (18/10/2026)
1. Conservez une copie PC de votre sauvegarde et de la v1.1 qui fonctionne.
2. Copiez les fichiers générés à la racine SD ; fusionnez .superfw.
3. Utilisez le cache BETA1 fourni : PatchEngine, RTC ACTIVÉE, DirectSaving activé,
   IGM et cheats désactivés. Ne régénérez pas le cache. Ne flashez pas le firmware.
4. Réglez date et heure dans les réglages SuperFW avant chaque session.
   Ce réglage est manuel ; sans puce RTC, SuperFW ne connaît pas le temps éteint.
5. Vérifiez les valeurs affichées ; START lance le jeu, L ouvre le réglage manuel.
   Gauche/droite : champ ; haut/bas : valeur ; START : mémoriser et lancer.
6. Si les données sont absentes/invalides, START ouvre le réglage manuel.
7. Le .sav facultatif est copié à l'identique dans SAVEGAME sous le nouveau nom.
   Même langue de ROM et de sauvegarde ; aucune conversion FR/EN.
   Adaptez le dossier si SuperFW en utilise un autre. Ne remplacez pas une partie récente.
BÊTA : trajet SuperFW/BIOS et vraie GBA non validés pour cette version.
L'heure avance pendant le jeu ; le temps éteint n'est pas compté.
Le défaut historique des choix dans les paramètres reste ouvert.

INSTALLATION — NyBy RTC v1.5-beta1 (2026-10-18)
1. Keep a PC backup of your save and your working v1.1 installation.
2. Copy the generated files to the SD root, merging .superfw.
3. Use the supplied BETA1 cache: PatchEngine, RTC ENABLED, DirectSaving enabled,
   IGM and cheats disabled. Do not regenerate the cache or flash the firmware.
4. Set the date/time in SuperFW settings before each session.
   This is a manual setting; without an RTC chip, powered-off time is unknown.
5. Review the displayed values; START launches, L opens manual adjustment.
   Left/right: field; up/down: value; START: remember and launch.
6. Missing/invalid firmware data: START opens the manual editor.
7. An optional .sav is copied unchanged into SAVEGAME under the new ROM name.
   Use the same ROM/save language; no FR/EN conversion is performed.
   Adjust the folder if configured differently. Never replace a newer save.
BETA: complete SuperFW/BIOS path and real GBA remain untested for this version.
Time advances during play; powered-off time is not counted.
The previously reported native Options choices issue remains open.
