# NyBy RTC v1.5-beta1 — EN / FR

## Français

Première bêta publique du pont SuperFW : lecture de son réglage manuel date/heure, écran minimal de confirmation et START pour lancer. L ouvre la correction directe avec la croix directionnelle, sans listes ni animation. Dernier réglage mémorisé, moteur assembleur en partie conservé.

Le paquet contient l'installateur HTML hors ligne, les BPS FR/EN, caches adaptés, sources MIT, guides FR/EN et résultats de tests. Aucune ROM, sauvegarde, traduction ou firmware.

**SuperFW 0.21 : PatchEngine, RTC ACTIVÉE, DirectSaving activé ; IGM/cheats désactivés. Nouveaux caches fournis obligatoires.** Mettre l'heure à jour dans SuperFW à chaque session. Le temps éteint reste inconnu ; ce réglage n'est pas une source d'heure automatique.

Validation PC : reconstruction depuis FireRed personnel, 29 contrôles du moteur, 11 parcours Chrome hors ligne, 10 ZIP vérifiés, reprise/sauvegarde/redémarrage mGBA FR/EN, calendrier et journée exhaustifs, recompilation identique des sources publiques. **Le trajet complet SuperFW/BIOS et la vraie GBA restent à valider pour cette bêta.** Les retours matériels v1.1 ne s'appliquent pas automatiquement ; le défaut historique d'affichage des choix dans les paramètres reste ouvert.

Pour essayer : télécharger et extraire le ZIP, ouvrir `INSTALLER-FR-EN.html`, sélectionner Unbound EN 2.1.1.1 ou FR Antony 2.1.179 sans ancien patch RTC et, facultativement, une copie de votre .sav de même langue. Conserver l'installation précédente et une sauvegarde PC. FireRed brut et anciennes ROM RTC ne sont pas acceptés par cette étape finale.

Principalement vibecodé avec Codex sous la direction de NyBy, qui avait besoin de cet outil et ne sait pas écrire lui-même le code nécessaire. Partagé librement pour les autres joueurs ; détail et crédits dans le kit.

## English

First public beta of the SuperFW bridge: import its manually configured timestamp, show a minimal confirmation screen and press START to launch. L opens direct D-pad adjustment, without dropdowns or animation. Last setting remembered; existing assembly clock runtime retained.

Includes the offline HTML installer, FR/EN BPS patches, matching caches, MIT source, bilingual guides and test evidence. No ROM, save, translation or firmware.

**SuperFW 0.21: PatchEngine, RTC ENABLED, DirectSaving enabled; IGM/cheats disabled. The new matching caches are required.** Update SuperFW's date/time every session. Powered-off time is unknown; this is not an automatic real-world time source.

PC validation: reconstruction from personal FireRed, 29 engine checks, 11 offline Chrome workflows, 10 verified ZIPs, FR/EN mGBA native save/resume/cold starts, exhaustive calendar/day checks and byte-identical public-source rebuilds. **The full SuperFW/BIOS path and real GBA remain untested for this beta.** v1.1 hardware feedback does not automatically validate v1.5; the previous native Options choices issue remains open.

To try it: download and extract the ZIP, open `INSTALLER-FR-EN.html`, select Unbound EN 2.1.1.1 or Antony FR 2.1.179 without an older RTC patch, optionally adding a copy of your same-language .sav. Keep the previous installation and a PC save backup. Raw FireRed and older RTC ROMs are not inputs to this final step.

Mainly vibe-coded with Codex, directed by NyBy, who needed this tool and cannot write the required code himself. Freely shared for other players; details and credits are included.
