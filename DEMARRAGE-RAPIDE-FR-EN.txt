ENGLISH

A clock for Unbound on a real GBA and a SuperCard without an RTC chip.
Set date/time at startup; they advance during play. Powered-off time is
not counted: correct the setting whenever you start the game.

PREPARATION BEFORE THIS INSTALLER:
EN: FireRed USA v1.0 -> Unbound 2.1.1.1 patch -> NyBy RTC EN patch.
FR: FireRed USA v1.0 -> Unbound 2.1.1.1 patch
    -> Antony French 2.1.179 translation patch -> NyBy RTC FR patch.
The NyBy package performs only the final RTC step. SHA-256 checks
recognize your already prepared Unbound build; they do not choose or
translate its language. The FR/EN selector changes only the interface.

1. Extract the community package on your PC.
2. Open INSTALLER-FR-EN.html in a modern browser, even while offline.
3. Select prepared Unbound and optionally its native 128 KiB .sav file.
4. Prepare and save your personal ZIP (~32 MiB).
5. Extract that ZIP and copy its contents to the SD card root.
   Back up existing files with matching names before replacing them.
6. SuperFW: PatchEngine, DirectSaving ON, RTC OFF, IGM OFF, cheats OFF.
   Do not run “Generate patches”: the caches are included.
7. Safely eject the SD. On GBA: date/time, START, Continue.

Games: original Unbound 2.1.1.1 EN, or Antony's French translation 2.1.179.
French inputs: this build without our RTC, RTC beta, or NyBy v1.0.
An already patched NyBy v1.1RC1 ROM is reused without double patching.
Plain FireRed and other game versions are not supported.
English GBA menu for the EN ROM; French menu for the FR ROM.
EN passed PC checks; its GBA test is pending. FR was tested on real GBA.
Use a save matching the ROM language; no FR/EN save conversion.

An included save is COPIED without conversion into SAVEGAME under the
matching ROM name. Adjust the location if SuperFW uses another folder.
Keep your original and a PC backup. Save states are not supported.

The RTC beta was tested on GBA; one user reports smooth gameplay with
optimized RC1. The intermittent Options issue remains open. This is not
a measured FPS result or a complete hardware validation.

Read README_EN.md for controls, troubleshooting, and limitations.
